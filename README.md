# Lancer le projet

Cloner le projet

source ./venv/bin/activate

rasa train

chmod +x start_rasa.sh

./start_rasa.sh

attendre bien une minute le dernier message attentu est : root  - Rasa server is up and running.

aller sur localhost:8000
